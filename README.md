# 生命森林 · 便携版看板

老杨的每日健康看板，做成普通网页文件，不锁在任何一个 AI 的空间里。
任何一个 AI 都能改它；数据存在 `data.json` 里，替换这个文件就能更新看板。

## 文件

- `index.html` — 看板页面（深绿 ANTHOS 风格，手机友好）
- `app.js` — 纯前端渲染，从 `data.json` 读数画图（canvas，无外部依赖，不联网也能打开）
- `data.json` — 全部真实数据，来自飞书多维表格「生命森林」
  （https://my.feishu.cn/base/EqNYbA8PPaTzMPsYHjxck0WqnRc，2026-11-13 导出核对）
- `README.md` — 本文件

## 规则（写死在页面里的）

- 主曲线只看体脂和肌肉，不看体重。
- 没有数据的日子显示「待记录」，不编数。
- 手动记录优先于手表。
- 本页不存任何密钥、Token，也不向任何地方发数据。

## 以后数据怎么更新

1. 从飞书「生命森林」把 7 张表（每日身体指标、训练记录、睡眠记录、补剂清单、每日补剂打卡、
   每周小结、体检报告）重新导出，按 `data.json` 现在的结构替换对应数组即可。
2. 以后也可以让阿里云 FC 函数（手表同步那条链路）在写飞书的同时，再写一份同样结构的
   `data.json` 到这个仓库，页面就自动是新的了。——这一步还没做，做的时候注意：
   函数里只写数据，不写密钥；密钥只留在函数环境变量里，绝不进仓库。
